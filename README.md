# Location Awareness Google Street Image Retouching with Seasonal Changes

A system for simulating seasonal changes of street trees in Google Street View images, combining deep learning, computer graphics, and automated data collection.

This project is based on my Master's thesis at National Chi Nan University, and was presented as first author at the **Japanese Society for Artificial Intelligence (JSAI 2025)** in Osaka, Japan.

---

## Overview

Google Street View images are static — they capture a single moment in time and cannot reflect seasonal changes. This system addresses that limitation by automatically replacing street trees with seasonally-adapted versions, allowing users to visualize what a street looks like in spring, summer, autumn, or winter.

![System Pipeline](docs/pipeline.png)

### Pipeline

1. **Data Collection** — Automated Selenium crawler collects daily screenshots from 100+ YouTube live cameras across Japan and Europe, building a 3-year time-series image database
2. **Semantic Segmentation** — U-Net model extracts tree canopy regions from Google Street View images at pixel level
3. **Image Inpainting** — SAM + LaMa removes the original tree and reconstructs the background
4. **L-System Morphing** — Procedural tree structure is generated and used to drive TPS (Thin Plate Spline) warping of seasonal canopy images
5. **Color Transfer** — Reinhard color transfer adapts canopy colors to match the target season and lighting conditions
6. **Compositing** — Warped seasonal canopy is blended back into the street view background

## Key Module: L-System Canopy Morphing

`lsystem_canopy_morph.py` is the core contribution of this project. It uses L-System branch structures to drive realistic deformation of tree canopy images via Thin Plate Spline (TPS) warping.

**How it works:**
1. Generate two L-System branch skeletons — one representing the initial tree state, one representing the target seasonal state
2. Build a dense grid of control points inside the canopy mask
3. For each control point, find its closest branch segment and compute the displacement based on the rotation and scale change between the two skeletons
4. Apply TPS warping to smoothly deform the entire canopy image

**Adjustable parameters:**
```python
angle_initial  = 10   # branch spread angle for initial state
length_initial = 5    # branch length for initial state
angle_extreme  = 10   # branch spread angle for target state
length_extreme = 8    # branch length for target state
```

**Usage:**
```bash
python lsystem_canopy_morph.py --input canopy.png --output result.png --show
```
